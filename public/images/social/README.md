# Instagram strip photos

Six square photos for the "Follow the making" row on the homepage.

```
instagram-1.jpg
instagram-2.jpg
instagram-3.jpg
instagram-4.jpg
instagram-5.jpg
instagram-6.jpg
```

- **Shape:** square, 800 × 800 px
- **Format:** `.jpg`, `.png`, `.webp` or `.avif`

Easiest approach is to download six of your own Instagram posts and rename
them. They're only decorative — each one links straight to your Instagram
profile, so they don't need to match a specific post.

The alt text for each is written in
`src/components/home/InstagramStrip.tsx`. If you use quite different photos,
update that text so screen readers describe them accurately.
