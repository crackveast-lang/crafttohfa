# Photos for the Our Story page

Drop files in here with these exact names. No code changes needed.

| Filename | Where it appears | Shape |
|---|---|---|
| `founder.jpg` | Homepage founder strip + About page | Square, 800 × 800 px |
| `workshop-1.jpg` | About page "Where it happens" strip | Landscape, 900 × 600 px |
| `workshop-2.jpg` | Same strip, middle | Landscape, 900 × 600 px |
| `workshop-3.jpg` | Same strip, right | Landscape, 900 × 600 px |

`.jpg`, `.png`, `.webp` and `.avif` all work — no need to convert.

**A note on `founder.jpg`:** it's displayed inside an organic blob shape, so
keep the face well inside the frame rather than near an edge.

Good candidates for the workshop three: yarn and hooks on the work table, a
rakhi mid-stitch, and orders boxed up ready to post. They don't have to be
polished — slightly imperfect, real photos suit this brand better than styled
stock ones.
